# 📝 To-Do List Application

## 📌 Опис проєкту

Цей проєкт є простим застосунком **To-Do List**, створеним на Python з використанням бібліотеки `customtkinter`.  
Застосунок дозволяє користувачу створювати, виконувати та видаляти задачі у зручному графічному інтерфейсі.

---

## ⚙️ Функціонал

- ➕ Додавання нових задач
- ✔ Позначення задач як виконаних
- ❌ Видалення задач
- 📋 Відображення списку задач
- 💾 Збереження задач у файл `tasks.json`
